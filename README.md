# PinMark 原型钉

> 把原型钉在同一页 —— 在真实可交互的 HTML 原型上直接打点、框选、补说明，导出带标注的只读页面交付研发。

2026-06-01：
  工具重命名为pinmark

## 解决的问题

传统的原型标注方式有各种痛点：

- **截图 + 红框箭头**：静态标注，无法体现交互逻辑，多页面/多状态需要截 N 张图
- **Figma/设计工具标注**：需要设计师手动维护标注图层，多人协作容易混乱
- **在代码里写注释**：PM 和设计师无法直接参与，沟通链路长
- **第三方标注平台**：需要注册账号、上传文件、有隐私风险，且通常收费

PinMark 的思路是：**直接在可交互的 HTML 原型上标注**。一个 HTML 文件搞定一切，标注跟原型绑定在一起，研发拿到手就能逐个对照查看。

## 特点

- **零依赖**：纯静态单文件 HTML，浏览器打开即用，无需安装、无需注册、无需后端
- **真实交互**：标注覆盖在可交互原型上，不是死截图，你可以在标注的同时正常操作原型
- **智能定位**：标注绑定到 DOM 元素，不是死坐标，元素位置变化后标注自动跟随
- **上下文感知**：SPA 切换页面/弹窗遮挡时，标注自动显示或隐藏
- **离线可用**：所有数据存 localStorage，无网络也能用
- **隐私安全**：原型文件完全在本地处理，不上传到任何服务器

## 快速开始

1. 下载 `html-annotation-tool.html`，浏览器打开
2. 点击「📂 选择 HTML 文件」导入你的原型
3. 切换到 **标注模式**
4. **点击**打点标注 / **拖拽**框选区域标注
5. 在右侧面板编辑标注的类型、标题和说明
6. 点击「📤」导出研发标注版 HTML，发给研发

> 关闭页面前标注会自动保存，下次打开可点击「恢复本地草稿」继续工作。

## 功能详解

### 两种工作模式

| 模式 | 用途 |
|------|------|
| **浏览模式** | 正常操作原型，点击按钮、填写表单、页面跳转都不受影响 |
| **标注模式** | 在原型上打标注，点击打点、拖拽框选，滚轮滚动原型内部页面 |

### 标注类型

每条标注支持 5 种分类：

- **交互** — 点击、跳转、手势、动画等交互行为说明
- **样式** — 颜色、字体、间距、圆角等视觉还原要求
- **数据** — 接口字段、数据格式、状态映射等后端相关
- **状态** — loading、empty、error、hover、disabled 等状态说明
- **疑问** — 需要确认或讨论的问题

### 点位标注 vs 区域标注

- **点位标注**：在页面上点击放置一个圆形编号标记，适合标注按钮、输入框等单个元素
- **区域标注**：拖拽框选一个矩形范围，适合标注整个模块/卡片/区块，编号角标显示在框的左上角

### 智能定位系统（核心）

PinMark 不只是记录屏幕坐标，而是建立标注与 DOM 元素的绑定关系：

**锚点绑定**
- 标注时自动捕获点击位置对应的 DOM 元素，生成 CSS 路径（如 `#login-btn` 或 `div.card:nth-of-type(2) > form`）
- 导出后，标注会跟随锚点元素的位置变化自动重新定位

**坐标模式自动识别**
- 文档流元素 → 记录文档坐标（document mode），随滚动偏移
- fixed/sticky 浮层元素（如顶部导航、弹窗）→ 记录视口坐标（viewport mode），不随滚动偏移

**页面上下文追踪**
- 记录当前页面的 route hash、页面根元素指纹（可见文本哈希）、以及弹窗/浮层上下文
- SPA 切换到其他页面后，不属于当前页的标注自动隐藏
- 弹窗/对话框打开时，被遮挡的标注自动隐藏

**导出后的持续追踪**
- 导出的研发版 HTML 内置 MutationObserver，监听 DOM 变化（元素增删、class 切换、属性变更）
- 同时监听 scroll、resize、click、input、transitionend、animationend 等事件
- 标注位置在 80ms 内刷新，保证始终跟随元素

### 导出格式

**1. 项目 JSON（`.json`）**
- 包含完整 HTML 源码 + 所有标注数据
- 可重新导入 PinMark 继续编辑
- 适合团队间传递工作进度、备份

**2. 研发标注版 HTML（`.html`）**
- 独立可运行的只读页面
- 布局：左侧原型预览 + 右侧标注清单
- 点击标注清单 → 原型自动滚动定位
- 点击原型上的编号标记 → 清单高亮对应条目
- hover 编号标记 → 浮出 tooltip 查看详情
- 同样支持智能定位和遮挡隐藏

### 标注管理

- **右侧清单**：按编号排列所有标注，点击可定位到对应位置
- **编辑器**：选中标注后可修改类型、标题、说明文字
- **定位按钮**：一键滚动原型到选中标注所在位置
- **删除**：支持单条删除

### 自动保存

- 每次增删改标注后 220ms 自动写入 localStorage
- 顶部状态栏显示保存状态（保存中 / 已自动保存）
- 存储空间不足时会提示导出 JSON 备份

## 适用场景

- 前端原型走查、设计还原度评审
- SPA 多页面/多状态原型的逐页精细标注
- 给外包或远程研发团队交付带标注的交互原型
- 产品评审会前整理问题点，会上逐条过
- 个人项目或小团队，不想为标注工具折腾账号和付费

## 浏览器兼容

支持所有现代浏览器：Chrome / Edge / Firefox / Safari。

## 技术实现

- 纯静态单文件，内联 CSS（约 750 行）+ JS（约 550 行）
- 通过 iframe `srcdoc` 嵌入原型，sandbox 保证安全隔离
- 使用 Pointer Events API 处理标注绘制手势
- 利用 TreeWalker + 可见文本哈希生成页面指纹
- 导出 HTML 通过 MutationObserver + 多种 DOM 事件实现标注持续追踪
- 坐标计算兼容 viewport/document 双模式，自动识别浮层元素
